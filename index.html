PolyU 备忘录 · v2 · 本地优先

接上学校邮件

一次性配置，大约 15 分钟。之后每天 12:30，脚本会读你 Gmail 里「学校」标签下的邮件，把摘要写进同一个 Gist。

  1. 建标签：在 Outlook 里设规则，把 PolyU 发来的邮件转发到 7et3rnity@gmail.com。
  2. 在 Gmail 建过滤器：收件人是你、来自 polyu 的邮件，自动打上「学校」标签。
  3. 创建 token：GitHub → Settings → Developer settings → Fine-grained tokens，只给 Gist 读写。
  4. 先同步一次：去「设置 → 同步」填 token 并连接，拿到 Gist ID。
  5. 部署脚本：打开 script.google.com 新建项目，粘贴仓库里的 tools/polyu-digest.gs，把 Gist ID 和 token 填进脚本属性。
  6. 设触发器：Apps Script → 触发器 → 每天 12:30，运行 dailyDigest。

细节和排错写在仓库 README 的「邮件摘要」一节。配好后点「刷新」就能看到摘要。
